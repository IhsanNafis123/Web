# Personal Portfolio Website — Ihsan Nafis Hidayat

Website Personal Portfolio modern, responsif, dan interaktif yang dibangun dengan **React**, **TypeScript**, dan **Tailwind CSS**.

---

## 🌟 Fitur Utama

- **Pembaruan Institusi:** Menggunakan **Universitas Harkat Negeri** (nama baru / transformasi dari Politeknik Harapan Bersama).
- **Semua Kompetisi & Prestasi:** Section khusus rekam jejak kompetisi (*Lomba Inovasi Solusi Digital*, *Novo Leadership Challenge Hackathon*, *Kompetisi UI/UX*, dsb.).
- **Data Terverifikasi:** Mengintegrasikan proyek nyata digitalisasi UMKM kuliner *Cafe Cosmic Cup* (terpublikasi di *Journal of Applied Community Service (JACS) 2025*), dan keikutsertaan *Novo Club Batch 3 (ParagonCorp)*.
- **Responsif Penuh:** Mobile (320px–639px), Tablet (640px–1023px), Desktop (1024px+).
- **Dark & Light Mode:** Toggle transisi tema instan tanpa flicker.
- **Bilingual (ID / EN):** Switch instan Bahasa Indonesia dan English.
- **Interactive CV Preview & Print:** Modal resume lengkap siap cetak / simpan ke PDF.
- **Filterable Projects:** Filter proyek berdasarkan kategori (Web Apps & UMKM, Akademik, Sosial).
- **Form Kontak Terintegrasi:** Validasi input formulir dan saluran langsung (WhatsApp, Email, LinkedIn).

---

## 🚀 Cara Menjalankan

### Mode Pengembangan (Development)
```bash
npm run dev
```
Buka peramban di `http://localhost:5173`.

### Build Produksi (Production)
```bash
npm run build
npm run preview
```
Output tersimpan di direktori `dist/` dan siap dideploy ke Vercel, Netlify, atau GitHub Pages.
